# Synthetic-to-Real Calibration Gap 示意图说明

## 图示表达

这张图说明当前 Query-aware Predictor 在 synthetic / proxy 模型空间中训练，并通过人工代理映射接入真实 DeepSeek 模型。代理映射能够打通真实 API 实验链路，但预测概率、真实质量、Token 和时延分布之间仍存在校准缺口。

图中下方给出下一阶段闭环：使用真实模型历史记录完成概率与阈值重校准，并通过在线反馈持续更新模型表现估计。

## 建议配套说明

当前 Predictor 学习的是 synthetic 模型空间中的质量规律，接入 DeepSeek 时采用了尚未校准的代理映射。真实模型的质量、输出长度和服务时延分布发生偏移，因此预测概率不能直接等同于真实通过概率。下一阶段将使用真实历史数据进行模型级阈值校准，并引入在线反馈持续更新路由依据。
